Hindavi Tours & Travels Platform

HTML5 CSS3 JavaScript Python Flask SQLite Render

Project Overview

A customer-focused web application for booking tour packages and vehicle rentals across Western India. Features custom destination showcases, package details, fleet specs, and customer inquiries with persistent database storage. Hosted live on Render cloud.

Key Features:

  • Live Production Deployment: Available globally at hindavi-tours-travels.onrender.com.
  • Dynamic Package Explorer: Highlighting popular tourist packages with itinerary details, pricing, and photo galleries.
  • Fleet Management Showcase: Detailed specifications and booking inquiries for diverse rental vehicles.
  • Inquiry & Booking Pipeline: Integrated with SQLite and Python Flask backend for storing customer requests.
  • Interactive UX: Custom animations, testimonials, sticky navigation, and fast mobile response.

Featured Full-Stack Project

Atelier - Online Clothes Shopping Website

HTML5 CSS3 JavaScript GCP Admin Portal

Project Overview

Atelier is a full-featured e-commerce fashion storefront crafted to deliver a modern, luxury shopping experience. Designed from the ground up with semantic HTML5 and responsive CSS3, it offers fluid navigation across desktop, tablets, and smartphones.

Key Features & Technical Implementation:

  • Product Catalog: Dynamic item showcase with high-definition imagery, category filters, and detailed view modals.
  • Interactive Cart System: Real-time JavaScript cart managing item quantities, pricing totals, and local storage state.
  • Complete Checkout Flow: Step-by-step user checkout from address input to order confirmation and order tracking.
  • Admin Dashboard: Separate secure admin section for catalog overview, product modifications, and order status updates.
  • Cloud Deployment: Hosted publicly on Google Cloud Platform (GCP) with firewall and server security configurations.

Tech Stack:

HTML5, CSS3, JavaScript ES6+, Python Backend, Google Cloud Platform, Git/GitHub.
